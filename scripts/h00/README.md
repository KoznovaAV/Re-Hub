# Технический эксперимент H-00

Проверяет получение одинакового списка из XLSX через LibreOffice Calc и через реальный Go API/PostgreSQL. Это автоматизация, участников-администраторов нет. Microsoft Excel не запускался.

Наборы: 30 и 4000 синтетических клиентов, два периода, 12 контрольных случаев: обычный долг, ноль, исключение, неактивность, пропуск среза, выполненный звонок, нижний порог, закрытый клиент, неизвестное всего, точное граничное значение, наблюдение только во втором или третьем квартале. Эталонные ID заданы типами случаев независимо от SQL и формул. Экспертного утверждения нет.

Исходные XLSX уже содержат формулы отбора. Настройка формул, ручная работа, удобство интерфейса, обучение и скорость людей не измеряются. SHA256 проверяет неизменность входов. Перед прогоном исходные строки XLSX сверяются с JSON, по которому загружается тестовая БД.

Для каждого размера: один разогревочный и пять зачётных прогонов с чередованием порядка инструментов. Холодный прогон включает запуск приложения, получение списка, запись CSV и завершение приложения. PostgreSQL уже запущена, данные подготовлены до таймера. Отдельно измеряется пять запросов работающего API с чтением JSON и записью CSV. Время Calc включает импорт XLSX и экспорт таблицы; обе ветки затем сохраняют отдельный список ID. Объём внутреннего вывода различается, поэтому отношение времён не является оценкой выигрыша администратора.

## Повторить

Нужны Node, Go 1.25, Python с openpyxl, LibreOffice Calc и локальная PostgreSQL. Выполнять из корня репозитория:

```bash
node scripts/h00/generate.mjs
(cd backend && go build -o ../scripts/h00/rehub-api ./cmd/api)
(cd backend && go build -o ../scripts/h00/h00-fixture ./cmd/h00-fixture)
export H00_BENCH_DATABASE_URL='postgres://USER:PASSWORD@127.0.0.1:5432/h00_benchmark?sslmode=disable'
python scripts/h00/run.py
```

Команда fixture создаёт и очищает только БД с точным именем h00_benchmark. Все данные в ней одноразовые. Производственную БД использовать нельзя.

Готовые книги лежат в contracts/testing/h00. build-workbooks.mjs сохраняет исходник их построения с @oai/artifact-tool. Для обычного повтора книги пересоздавать не требуется.

Результаты: reports/h00/automated.json. В нём сохранены все времена, метрики, версии среды, хеши входов и итоговых ID. Исходная H-00 о работе двух администраторов оценивается отдельно по scripts/evaluate-h00.py.
