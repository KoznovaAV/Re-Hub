# H-02. Проверка связи и выбор роутера

Для скелета оставляем стандартный `net/http`. Связь Go → Python проходит контрольный сценарий. Ни chi, ни Gin не достигли порога смены роутера, записанного в [плане](../docs/experiments/H-02-plan.md).

## Замеры

Измерено 60 000 запросов после прогрева. Ноль ошибок. В таблице медианы пяти раундов. Среда: Linux amd64, Go 1.25.12, Python 3.12.14, GOMAXPROCS=2, один запрос одновременно. Точные данные каждого раунда лежат в [results.json](../backend/benchmarks/results.json).

| Режим | Роутер | Ошибки / запросы | p50, мкс | p95, мкс | Запросов/с | Пиковый RSS, МиБ |
|---|---|---:|---:|---:|---:|---:|
| route | net/http | 0/10 000 | 95,4 | 271,5 | 7 666,7 | 14,9 |
| route | chi | 0/10 000 | 95,2 | 271,1 | 7 835,8 | 14,9 |
| route | gin | 0/10 000 | 96,2 | 241,1 | 8 059,8 | 14,9 |
| probe | net/http | 0/10 000 | 817,3 | 1 719,2 | 1 056,9 | 15,7 |
| probe | chi | 0/10 000 | 853,9 | 1 652,4 | 1 034,4 | 15,6 |
| probe | gin | 0/10 000 | 872,0 | 1 881,4 | 982,3 | 15,7 |

Сравнение с net/http в режиме Go → Python. Отрицательное изменение p95 означает меньшую задержку.

| Роутер | Изменение p95 | Изменение запросов/с | Раунды с меньшим p95 |
|---|---:|---:|---:|
| chi | -3,89% | -2,12% | 2/5 |
| gin | 9,43% | -7,05% | 1/5 |

Для текущего API достаточно регистрации метода и пути стандартным ServeMux. Оба кандидата добавляют по одному прямому модулю роутинга. Gin подключает обработчик через WrapH. Зависимости замеров находятся в отдельном Go-модуле.

## Воспроизведение

Из корня репозитория запустите Python в одном терминале и замер во втором:

```bash
python3 ai-service/app/main.py
```

```bash
python3 backend/benchmarks/run.py > /tmp/rehub-router-results.json
```

Smoke проверен отдельным прямым запуском на Node.js 22.22.0. Все три /health вернули 200. До остановки Python и после запуска получены по 10 из 10 ожидаемых ответов. Во время остановки Go вернул 200 на /health и 503 на запрос связи. Некорректная версия в прямом запросе к Python дала 400. Тесты Go прошли с детектором гонок.

## Границы

Оба режима измеряют локальный HTTP при одном запросе одновременно. В режиме probe используется настоящий Python-сервис и контрольный JSON. В измерение не входят база, модель, XLSX и нагрузка нескольких операторов. Пиковый RSS относится к общему бинарнику эксперимента и берётся из Linux rusage. Небольшие различия RSS не используются для выбора. Журнал трудозатрат участников не предоставлен. Повторить сравнение при появлении рабочих маршрутов и параллельного трафика.
