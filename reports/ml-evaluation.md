# H-03 Проверка чтения на синтетических данных

Детерминированный эталон прошёл 20 из 20 контрольных кейсов и 3 из 3 проверок уточнения. Чужая запись не возвращалась. Запись и произвольный SQL отклонялись, исходные строки после каждого вызова оставались неизменными. Проверка выполняется через `cd ai-service && python -m unittest discover -s tests -v`.

## Сквозная проверка с Qwen в Codespaces

14 ноября 2026, модель `qwen3:1.7b` через Ollama, синтетические данные, тестовый оператор. Команда прогона из терминала Codespaces:

```bash
python3 scripts/smoke-ai-query.py --url http://127.0.0.1:3002/api/ai/query
```

| Сценарий | Что проверялось | Итог | Время, с |
|---|---|---|---:|
| SYN-01 | Нулевой долг | OK | 51,1 |
| SYN-02 | Нет записи за период | OK | 15,1 |
| SYN-06 | Недоступная запись клиента | OK | 16,9 |
| SYN-09 | Обещанный срок | OK | 16,5 |

Итого 4 из 4. Время измерено от отправки HTTP-запроса до получения ответа. Первый запрос занял 51,1 с, следующие три - от 15,1 до 16,9 с. Это один прогон.

- `TST00001`, 3 квартал 2026. Помощник показал 0 непереданных оригиналов из 16, дату среза 20.10.2026 и источник `test-slice-2026-10-20`.
- `7000016`, апрель-июнь 2026. Помощник распознал 2 квартал и показал 13 непереданных оригиналов из 18, источник `test-slice-2026-07-20`.
- На вопрос "Как обрабатываются дубли строк при импорте?" после [правки поиска](https://github.com/KoznovaAV/Re-Hub/commit/cf808976ef98fa31f6be64bef63f2585138f34bb) помощник вернул правило IM-01 об отклонении всего файла и указал [правила импорта](../docs/data/T-02_import_and_period_rules.md#im-01-дубли-отклоняют-весь-файл). Дополнительно процитировал соседнее правило о нечитаемом ключе. Оно относится к отдельному случаю и для ответа о дублях избыточно.
