# Q-01 — QA-сценарии администратора и оператора

**Задача:** Q-01, MUST, A-11. **Статус:** автоматизировано; фактический
E2E-прогон выполняется в CI Compose.

## Запуск

В CI сценарий запускается после Compose smoke:

```bash
docker compose exec -T parser-service python - < scripts/qa/run_qa.py
```

Локально при поднятом Compose:

```powershell
docker compose exec -T parser-service python - < scripts/qa/run_qa.py
```

## Результаты и дефекты

До фактического прогона в CI дефекты не фиксируются как найденные: скрипт
создаёт изолированные данные `QAA…` и проверяет реальные HTTP-коды и карточку.
После прогона результаты CI прикладываются к задаче; при падении в отчёте
остаются имя сценария и ответ API.
