# Фактический прогон стенда замеров агентом

Исполнитель: программный агент. Реальных участников: **0**. Данные синтетические. Это проверка сбора пользовательского протокола, а не пользовательское исследование.

В Chromium выполнены четыре прохода `/study` с двумя порядками инструментов. В базовом проходе агент скачивал исходный CSV, создавал книгу с формулой отбора, запускал настоящий LibreOffice Calc для вычисления и возвращал ID в форму. В Re:Hub агент менял фильтры страницы. Таймер `performance.now()` работал от предъявления задания до отправки ответа. Время не задано константами. Сохранены исходный журнал, CSV и результат оценщика.

Медиана базового пути Calc: 9.941 с; Re:Hub: 0.034 с. Качество списков: precision=recall=1; включений исключённых нет. Метка tool=excel в журнале обозначает базовый табличный путь, фактически использован LibreOffice Calc.

Эти два времени нельзя использовать как оценку ускорения людей: в Re:Hub агент мгновенно выполняет известные ему действия без чтения и размышления, а базовый путь включает запуск Calc и программную подготовку формулы. Два кода AGENT-ORDER обозначают порядок прогонов одного агента, не двух администраторов. Отношение времён является только диагностикой этого автоматизированного сценария. Оценщик возвращает `data_kind=agent_observed`, `human_participants=0`, `confirmed=false`.

[Журнал](agent-ui-journal.json), [протокол](agent-ui-protocol.csv), [оценка](agent-ui-evaluation.json). Повторение: `python3 scripts/tests/run_study_browser.py --chromium /path/to/chromium`.

Для настоящего пилота [инструкция](../../docs/scenarios/user-measurements.md): два человека проходят задания самостоятельно. Их времена регистрируются тем же интерфейсом и не заменяются временами агента.
