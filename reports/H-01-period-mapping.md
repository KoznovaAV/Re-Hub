# H-01 Период исходного XLSX

Критерий карты — 100% совпадений на всех строках как минимум десяти клиентов. Источник — октябрьский XLSX с четырьмя явно размеченными вкладками. Сверка проводилась двумя способами: чтение книги и чтение ячеек из исходного XML по координатам. Для десяти клиентов, присутствующих во всех четырёх периодах, совпали 40 из 40 координат и периодов.

**Вывод:** гипотеза подтверждена для предоставленной книги. Периоды доступны для 12 772 строк. При прогоне адаптера 12 768 строк разобраны, четыре строки с `#N/A` в ID отклонены. Среди разобранных строк есть два точных повтора пары ID и периода. Подтверждение импорта должно их блокировать по T-02.

Профиль, команды запуска и таблица периодов приведены в [описании импорта](../docs/data/customer-october-xlsx.md). H-05 снята для текущего источника. Исходный Excel доступен, поэтому резервная конвертация PDF для рабочего импорта не требуется.
