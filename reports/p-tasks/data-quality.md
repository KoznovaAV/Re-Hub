## Независимая проверка PDF и объяснение расхождения

Один и тот же PDF, один и тот же срез, одна регулярная маска ID.

| Метод | ID справочника | Неизвестных ID | Пропущено ID относительно XLSX |
|---|---:|---:|---:|
| pypdf | 5873 | 243 | 0 |
| pymupdf | 5873 | 243 | 0 |
| poppler_layout | 4141 | 1527 | 1732 |

Pypdf и PyMuPDF независимо восстановили ровно то же множество ID, что исходный XLSX. Poppler пропустил 1732 ID, из них 1284 встречаются в срезе. Поэтому неизвестных стало 1527, а не 243: разница равна 1284. Это воспроизводимая причина расхождения результатов по методам извлечения.

Число 1572 не воспроизводится ни одним из этих методов. Вариант 1527 подтверждён; предположение о перестановке цифр остаётся предположением. Для этих источников 1572 исключается из выводов как неподтверждённое утверждение.

Технический аудит P-04 завершён. Это не подтверждение полноты базы заказчика: остаются реальные 243 неизвестных клиента, и порог H-10 в 5% не пройден. Деловую причину их отсутствия должен объяснить поставщик.
