# Модуль `parser_ml` (canonical_xlsx_v1)

Модуль предназначен для извлечения, нормализации и синтаксической валидации данных из Excel-файлов (XLSX) в рамках ML-пайплайна. 
Парсер реализован как **чистая функция** (pure function) и не имеет побочных эффектов: он не пишет в базу данных, не делает `commit`, не зависит от внешних API и не сохраняет промежуточное состояние на диск.

## Основные характеристики
*   **Библиотека чтения:** `openpyxl` (выбрана за скорость работы и строгий контроль типов ячеек).
*   **Целевой профиль:** `customer_october_tabs_v1` (формат обезличенных данных).
*   **Режим ключей:** `anonymous` (ключи строго проверяются по регулярному выражению).

## Как использовать

```python
from parser_ml.core import parse_file

context = {
    "snapshot_date": "2026-10-31"
}

# Функция принимает путь к файлу и контекст
result = parse_file("path/to/snapshot.xlsx", context)

print(result["rows"])    # Список валидных строк
print(result["errors"])  # Список ошибок
