# Сверка с документом «Комментарии от заказчика»

Дата: 22.11.2026. Правки остаются в ветке fix/review-roles-and-workflow до решения о слиянии.

| Пункт документа | Поведение интерфейса |
|---|---|
| Видно, какой срез используется | Над фильтрами показаны выбранный период и дата последнего загруженного среза. Если данных нет, это написано явно |
| Фильтр по числу документов | Поле «Не передано документов от» независимо от доли |
| Период на главной | Выбор периода сохраняется при переходе к списку |
| Ежедневная задача администратора | Главная ведёт через загрузку данных, подготовку списка и работу операторов; аналитика вынесена отдельно |
| ВИП и отдельный тип клиента | ВИП доступен в фильтре даже при пустой выборке. В таблице отдельная колонка «Тип клиента». Признаки динамики не считаются типами |
| Лишние поля общего списка | В общей таблице нет колонки обещанного срока и статуса «В работе». Последний остаётся состоянием назначения в рабочем списке и карточке |
| Что означает «В работе» | Есть текущий ответственный оператор. Это не доказательство прежнего звонка или участия в старой кампании |
| Переназначения не засоряют общение | Сохраняются в техническом аудите, не включаются в историю звонков, писем и комментариев и в число звонков |
| Проблемные строки импорта | Предпросмотр показывает количество успешных строк и ошибки. Ошибки скачиваются в CSV. Для частичного приёма требуется явное согласие |
| Упрощённый экран оператора | Меню ограничено работой с клиентами. Доступны свои клиенты, общий рабочий список и подготовленный свободный пул |
| Контакт и звонок важнее цифр | Вверху карточки показаны контактные сведения, затем последний статус звонка, число недозвонов и дата переноса. Цифры документов и полная история расположены ниже |
| Возможность забрать клиента коллеги | Оператор может забрать чужого клиента себе, передать своего коллеге и освободить вручную. Администратор не распределяет клиентов |
| Статусная модель звонка | «Не звонили», «Недозвон» с количеством, «Перенос» с датой, «Не тот администратор». Прежнее название «Не тот контакт» читается совместимо и показывается новой формулировкой |

При отсутствии контакта или типа интерфейс показывает отсутствие данных, а не выдумывает их. Промышленная аутентификация и история кампаний остаются отдельными задачами. Этот документ не является подтверждением пользовательского ускорения H-00.
