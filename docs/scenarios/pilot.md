# Пилот списка обзвона и карточки клиента

Макет доступен на `http://127.0.0.1:3000/pilot` после запуска из README. Он использует два синтетических набора по 30 клиентов. CSV скачивается с той же страницы для ручного этапа в Excel. Эти наборы проверяют методику. Реальный эталон клиентов для #51 утверждается отдельно, с учётом согласованных правил.

## H-00 Список обзвона

Два администратора независимо выполняют одно задание на обоих инструментах. Первый начинает в Excel с A и заканчивает в макете с B. Второй начинает в макете с A и заканчивает в Excel с B. До каждого задания участник видит только назначенный набор. Требуется составить список III квартала с порогом восемь, только с наблюдением, без исключённых и без ранее обзвоненных за этот период. Измеряется время от предъявления задания до сохранения списка. Эталон рассчитывается по исходным колонкам CSV и отдельно проверяется Екатериной до сессии.

Запись для каждого прохода: код участника, инструмент, набор, секунды, ID из ответа, эталон, число ошибочно включённых исключённых клиентов. Критерии — сокращение медианного времени ≥50%, полнота ≥90%, точность ≥80%, ошибочных включений исключённых — 0.

## H-06 Карточка клиента

Два или три оператора выполняют по пять заданий в Excel и в макете. Инструменты и наборы чередуются. Для A используйте ID 01, 03, 04, 08 и 11, для B прибавьте 30. Задания проверяют наличие наблюдения III квартала, непереданные документы II квартала, факт звонка по нужному периоду, срок обещания и различение отсутствия наблюдения от нуля. Эталон для каждого ID фиксируется из CSV до сессии.

Запись: код оператора, инструмент, набор, задание, секунды, ответ, верно или неверно. Критерии — медиана ≤30 с и сокращение ≥30% к Excel, доля правильных ≥90%. Замеры и наблюдения пользователей на момент подготовки отсутствуют.
