# Пользовательский замер H-00 в интерфейсе

## Запуск

Запустите проект по README и откройте `/study` (в локальном Compose: http://127.0.0.1:3000/study). Для одного стенда без PostgreSQL: `REHUB_MODE=demo node frontend/src/server.mjs`, затем тот же путь. Стенд использует синтетические данные и не зависит от содержимого БД.

1. Организатор вводит два разных кода реальных участников и выбирает «Люди». Для проверки программы используется отдельный режим «Автоматизированная проверка».
2. Участник 1 проходит Excel A, затем Re:Hub B; участник 2 — Re:Hub A, затем Excel B. Время начинается при предъявлении задания кнопкой «Начать проход». Открытие CSV и сохранение ответа включены в интервал обоих инструментов.
3. В Excel скачайте исходный CSV, откройте его в Excel/Calc, выполните отбор и вставьте ID или загрузите CSV из одной колонки. Колонка observed позволяет отличить отсутствие наблюдения от нуля. Сведения о втором наборе не открывайте.
4. В Re:Hub задайте период 2026Q3 и порог 8. Страница дополнительно учитывает наблюдение, исключения и звонки. «Завершить и сохранить ответ» останавливает таймер и скачивает выбранные ID; ошибочный ответ сохраняется без исправлений.
5. После четырёх проходов организатор независимо проверяет эталон, раскрывает блок проверки и указывает код эксперта. Скачайте журнал JSON и протокол CSV. Запустите `python3 scripts/evaluate-h00.py h00-journal.json`.

До каждого прохода фильтры сбрасываются; ответы эталона скрыты до завершения всей сессии. Сессия сохраняется в localStorage этого браузера. После перезагрузки незавершённый проход помечается как прерванный; его время не подменяется новым отсчётом. Перед новой сессией скачайте журнал. Протокол можно экспортировать и до завершения, но оценщик не примет неполные четыре прохода.

## Что фиксируется

Код участника, исполнитель human/automation, инструмент, набор, время performance.now(), даты начала/окончания, ID ответа, precision, recall, пропуски и включения исключённых, переключения видимости вкладки и прерванные попытки. Переключение в Excel разрешено и не останавливает таймер. Таймер монотонный; перезагрузка не продолжает интервал другой временной шкалы.

Это сессия на упрощённом интерфейсе `/study`. Результат не переносится автоматически на основной рабочий интерфейс и всю работу администраторов. Синтетические данные допустимы для пользовательской проверки интерфейса, но экспертиза эталона и реальное участие людей остаются обязательными. Код эксперта — запись организатора, а не техническое доказательство участия.

## Выполненная проверка стенда

[Фактический прогон Chromium и Calc](../../reports/h00/browser-workflow-method.md). Все четыре интервала получены во время выполнения. Исполнение автоматизированное; human_participants=0, confirmed=false. Эти времена проверяют запись протокола и вычисление метрик, не подтверждают ускорение людей.

Повторить: `python3 scripts/tests/run_study_browser.py --chromium /path/to/chromium`. Нужны Playwright, openpyxl и LibreOffice Calc. Основной CI выполняет модульные тесты стенда; браузерный прогон запускается отдельно.
