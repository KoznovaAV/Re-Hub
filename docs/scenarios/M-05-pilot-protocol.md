# M-05 — протокол пилота H-00

M-05 фиксирует пользовательский пилот H-00 с **двумя разными администраторами**.
Один участник проходит Excel A → Re:Hub B, второй — Re:Hub A → Excel B.
Нужны четыре реальных прохода, два независимо согласованных эталона и код
эксперта, который проверил эталон.

## Что должно быть в журнале

- `data_kind: measured`;
- два разных `participant`;
- по два прохода на участника: `excel` и `rehub` на разных наборах `A`/`B`;
- 15 ID в каждом наборе, `expected`, `excluded`, `approved_by`;
- реальные секунды и итоговые ID ответа;
- precision/recall и отсутствие включений исключённых клиентов.

Синтетические и автоматизированные прогоны не заполняют M-05 и не подтверждают
ускорение людей. Они остаются отдельными учебными/техническими материалами.

## Сборка протокола

```powershell
py -3 scripts/h00/m05_protocol.py h00-journal.json --out reports/h00/Q-03-M-05-protocol.md
```

Скрипт проверяет структуру через `scripts/evaluate-h00.py`, требует
`data_kind=measured` и двух участников, затем формирует таблицу проходов,
медианы, скорость и критерии H-00.
