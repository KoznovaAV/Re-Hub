# Ответственность Python и Go

Python преобразует источник в ParserResult v1. Контекст передаётся отдельно. В версии адаптера октябрьского XLSX Python читает явные вкладки и сохраняет координаты. Python не применяет правила истории и не пишет в БД.

Go владеет проверкой дублей, проверкой справочника, наследованием total, preview, правами и атомарным commit. Строки с дублями ID и периода отклоняются; корректные строки обрабатываются отдельно. Технический отказ Python должен отличаться от успешного импорта с нулём строк. Текущий HTTP probe проверяет доступность и сбой связи. Вызов рабочего парсера из Go остаётся в #58.
