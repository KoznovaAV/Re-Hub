# Ответственность Python и Go

Python преобразует источник в ParserResult v1. Контекст передаётся отдельно. В версии адаптера октябрьского XLSX Python читает явные вкладки и сохраняет координаты. Python не применяет правила истории и не пишет в БД.

Go владеет проверкой дублей, проверкой справочника, наследованием total, preview, правами и атомарным commit. Дубль пары ID и периода блокирует подтверждение. Технический отказ Python должен отличаться от успешного импорта с нулём строк. Текущий HTTP probe проверяет доступность и сбой связи. Вызов рабочего парсера из Go остаётся в #58.

Контракт: [контекст](../../contracts/import-context.schema.json), [ParserResult](../../contracts/parser-result.schema.json), [примеры](../../contracts/examples/). Для ML используется отдельная граница чтения, описанная в [контрольных сценариях](../ml/tools-v1.md).
