# Контрольные сценарии чтения для H-03

В синтетическом эталоне два метода: `get(client, period)` и `list(period, minimum)`. Допустимый набор клиентов передаёт вызывающий сервер. Модель не должна выбирать или расширять его. Для теста закреплены идентификаторы A, B, C и отдельная недоступная запись OUT. Фикстура различает нулевой долг, пустую выборку и отсутствие наблюдения. Ответы с данными возвращают дату и источник.

Эталон и ожидаемые результаты лежат в `ai-service/tests/test_pilot_read.py`. Первые 20 кейсов проверяют точную выборку, границы, отсутствующие записи, запрос чужого клиента и запрет записи и произвольного SQL. Три последних требуют уточнения.

Для полного прогона направить эквивалентные запросы к модели через рабочий API. Зафиксировать версию модели, серверный scope, вызовы и их результат, фактический ответ и время. Сравнить на тех же заданиях с обычными фильтрами. Критерии карты: 20/20 точных ответов, 3/3 уточнения или отказа, ноль чужих записей и операций записи, выигрыш по медиане времени ≥30%.
