# Re:Hub — Контур MVP

Сервис для автоматизации контроля передачи оригиналов документов корпоративными клиентами (КЦР). 
Позволяет загружать срезы, автоматически считать динамику, формировать список на обзвон и вести историю взаимодействия с клиентом.

## 🏗 Архитектура
Проект использует модульный монолит (Go) и выделенный сервис для работы с ИИ (Python):
*   **Frontend:** Vue.js
*   **Backend (Домен):** Go (chi, pgx, goose)
*   **Backend (ИИ):** Python (FastAPI)
*   **База данных:** PostgreSQL

## 📂 Структура проекта (план)
*   `apps/web` — интерфейс администратора и оператора
*   `apps/api-go` — основной API, бизнес-логика, работа с БД
*   `apps/ai-python` — сервис ИИ-помощника (обработка запросов)
*   `contracts/` — OpenAPI спецификации
*   `db/migrations/` — SQL-миграции базы данных

## 🚀 Как запустить (черновик)
Для запуска всех сервисов используется Docker Compose.

1. Убедитесь, что у вас установлен Docker и Docker Compose.
2. Клонируйте репозиторий.
3. В корне проекта выполните команду:
